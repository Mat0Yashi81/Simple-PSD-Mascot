Simple PSD Mascot v1.0.0
初回正式公開版

このアプリについて
ユーザーが用意したPSDを読み込み、服装・表情の切り替え、まばたき、口パク、タッチによるリアクション、放置時の動作、音声再生を行うデスクトップマスコットです。PSDや音声素材は同梱していません。

対応環境
Windows 10 / 11 の64ビット（x64）版を想定しています。
動作確認はWindows 11で行っています。すべての環境・PSDでの動作は保証しません。
exe版はPythonのインストールが不要です。

起動前の準備：Microsoft Visual C++ x64ランタイム
Microsoft公式の最新Visual C++ x64ランタイムをインストールしてください。
公式案内：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
公式ダウンロード：https://aka.ms/vc14/vc_redist.x64.exe
ダウンロードしたvc_redist.x64.exeを実行し、Microsoftの条項に同意してインストールします。再起動を求められた場合は再起動してください。対応版が既に入っている場合、追加インストールは不要です。
Microsoft製ランタイムDLLは本ZIPに同梱していません。

使用方法
1. ZIP全体を書き込み可能な新しいフォルダへ展開してください。
2. Simple-PSD-Mascot.exeを起動し、自分で用意したPSDを開きます。
3. 「レイヤー」で表示するパーツを選び、「服装」で衣装を保存・呼び出しします。
4. 「動き」で目・口・眉などのレイヤーを割り当て、「表情」で動きのプリセットを保存・呼び出しします。
5. デスクトップに立ち絵を表示して使用します。右クリックの「着替え」は服装ごとの「着替え」チェックを有効にすると使えます。
6. 「セリフ」でWAV・MP3・OGG音声を登録します。「ボイス」を有効にした項目は立ち絵の右クリックから再生できます。
7. 「リアクション」でタッチ範囲・表情・セリフ・持続時間を設定できます。「放置」はこのアプリやマスコットを操作していない時間に動作します。
8. 「設定」で表示倍率、まばたき、口パク、フォント、キャッシュなどを調整できます。ログは初期状態でオフです。
9. ウィンドウを閉じるか、通知領域のメニューの「終了」で終了します。

ファイルの取り扱い
exeだけを移動せず、同梱の_internalフォルダも保持してください。
Program Filesなど通常書き込めない場所への展開は避けてください。
voiceとcacheは実行時データ用です。設定は互換性のためAppData以下のPSD Mascot/PSD Mascot/v0.4.1に保存します。この内部名は正式版のバージョン表記とは別です。旧版の設定を引き継ぐ場合があります。
PSD自体を書き換える機能はありません。素材は各権利者の規約に従って使用してください。キャッシュ生成により素材の再配布が許可されるわけではありません。
