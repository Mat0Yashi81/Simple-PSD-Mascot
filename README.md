## 正式名称・アイコン

正式名称は **Simple PSD Mascot** です。Windowsのexeは `Simple-PSD-Mascot.exe`、フォルダ名は `Simple-PSD-Mascot-v1.0.0` です。
正式アイコンをエクスプローラー、タスクバー、ウィンドウ、通知領域に設定しています。
通知領域のアイコンはWindowsの「隠れているインジケーター」に入る場合があります。
右クリックの「開く」またはダブルクリックでメイン画面を表示でき、「終了」でアプリを終了します。
通常のウィンドウを閉じた場合もアプリは終了します。終了動作を常駐化へ変更するものではありません。

アイコンPNGと派生ICOも、利用者の指定によりMITライセンスです。`ASSETS.md` を参照してください。
設定の互換性のため、保存先の歴史的な `PSD Mascot/PSD Mascot` という名前は維持しています。
PSDの解析・合成・キャッシュキーの仕様は変更していません。

## Windows版の起動

1. Microsoft公式の最新Visual C++ x64ランタイムをインストールします。既に対応版が入っていれば追加インストールは不要です。Microsoft製DLLは本ZIPに同梱しません。
   - 公式案内: https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
   - 公式x64版: https://aka.ms/vc14/vc_redist.x64.exe
   - ダウンロードした `vc_redist.x64.exe` を実行し、Microsoftの条項に同意してインストールします。再起動を求められた場合は再起動します。詳細は `PREREQUISITES.md`。
2. Windows ZIPを、書き込み可能な新しいフォルダに**全体を展開**します。
3. `Simple-PSD-Mascot.exe` を起動し、自分で用意したPSDを開きます。

**exe版にPythonのインストールは不要です。** `_internal/` は必要なライブラリなので、exeだけを別の場所に移さないでください。Program Filesなど、通常の書き込みができない場所は避けてください。

想定環境はWindows 10/11 x64ですが、今回確認したOSはWindows 11です。すべてのWindows環境やPSDでの動作を保証しません。未署名exeのためWindowsの警告が出る場合があります。

`voice/`・`cache/` は実行時データの保存先です。設定はユーザーのAppData以下の `PSD Mascot/PSD Mascot/v0.4.1/` に保存します。旧版の設定を引き継ぐ場合があります。ログは初期状態でオフです。PSD自体を書き換える機能はありません。

PSDや音声の利用・公開は各素材の規約に従ってください。PNGキャッシュを生成しても、素材の再配布許可が得られるわけではありません。

## 右クリックから着替え

立ち絵の右クリックメニューに「着替え」を追加しました。

1. 「服装」タブで服装を保存します。
2. 一覧から、右クリックメニューに表示したい服装を選択します。
3. 「着替え」チェックボックスをオンにします。
4. デスクトップの立ち絵を右クリックし、「着替え」から服装名を選びます。

チェックは保存済みの服装プリセットごとの設定です。初期状態はオフで、チェックした服装だけをメニューへ表示します。項目がないとき「着替え」は無効表示になります。チェック状態はPSDごとに保存し、次回起動時に復元します。

メニュー順は「服装」タブの一覧順です。上下移動・チェック解除・削除をメニューにも反映します。同じ名前で上書き保存した場合はチェックを維持し、呼び出すレイヤー状態を最新に更新します。削除後に同じ名前を新規作成した場合は、初期状態の未チェックになります。

服装タブと右クリックは同じ服装適用処理を使います。現在の表情・目口の割り当てを維持して服装を切り替え、一覧の選択とプレビュー・デスクトップ表示へ反映します。放置アクション中なら通常のユーザー操作として中断・復元してから着替えます。PSD読込や一括生成・キャッシュ管理中は変更しません。処理完了後に選び直してください。

PNGの形式・識別キーは変更していません。PSD別設定はschema 7で、従来の服装レイヤー表示辞書とは別に `outfit_menu`（メニューに出す服装名の一覧）を追加しました。v0.4.0以下のデータにはこの項目がなくても読み込めます。その場合、服装は従来どおり使え、右クリックへの表示は未チェックから始まります。旧版のデータは読み取りのみで引き継ぎ、新しい保存先はv0.4.1です。

## v0.4.0から継続：放置タブ

「リアクション」と「セリフ」の間に「放置」を追加しました。当たり判定は使わず、マスコット・このアプリに対する操作がない時間で動作します。他のアプリでのキーボード・マウス操作は放置時間をリセットしません。

### 設定方法

1. PSDを開き、「表情」や「セリフ」に使いたいプリセットを用意します。
2. 「放置」で共通の「放置時間の下限」「放置時間の上限」を指定します。初期値は30.0〜60.0秒です。
3. 「放置アクションを追加」で項目を作り、名前・呼び出す表情・呼び出すセリフ・持続時間を設定します。表情だけ、セリフだけの指定も可能です。
4. 「放置アクションを有効にする」と、項目ごとの「このアクションを有効にする」を確認します。初期値は両方オンですが、項目がない状態では何も実行しません。
5. 立ち絵をデスクトップに表示します。表示中だけ自動実行します。

待ち時間は全項目共通の範囲から、実行のたびにランダムに選びます。実行時は、有効な表情または存在する音声ファイルを持つ有効項目から1つを均等にランダム選択します。上下移動は一覧と保存順の整理用です。項目を順番に実行する方式ではありません。

下限・上限は0.1〜86400.0秒、持続時間はリアクションと同じ0.1〜600.0秒です。片側を変更して下限が上限を超える場合は、もう片側も調整します。

「選択した放置アクションを試す」は、立ち絵をデスクトップに表示していない場合や自動実行を無効にしている場合にも、選択した項目の表情・音声を確認できます。プレビューに当たり判定のボックスは出しません。

### 実行・中断の動作

- 表情の持続時間は、描画が完了して実際に表示されてから数え、その後に元の表情へ戻します。
- 表情とセリフを両方指定した場合は、表情の準備ができてから音声を再生します。口パクは設定タブの指定に従います。
- セリフは持続時間で途中停止せず、最後まで再生します。次の待ち時間はアクションと音声の終了後に取り直します。
- アプリや立ち絵へのクリック・タップ・ドラッグ・キー入力・ホイール操作などで待ち時間を取り直します。放置アクションの途中なら元の表情へ戻し、その放置アクションが再生した音声を停止します。手動で再生した音声を放置処理が停止することはありません。
- タッチの手動リアクションを優先します。手動リアクション・音声再生・PSD読込・一括キャッシュ生成・キャッシュ管理・ダイアログ表示中は自動実行を待機し、終了後に新しい待ち時間を選びます。
- 立ち絵を閉じている間は自動実行しません。再表示時に待ち時間を取り直します。

放置時間の判定はタイマーで行います。設定範囲から待ち時間を選んだ後、描画処理などの準備ができたタイミングで実行するため、表示が始まる時刻には処理時間やタイマーの誤差が加わります。

### 保存と旧版

待ち時間・有効状態・アクション一覧はPSDごとに保存します。新しい保存先は `%APPDATA%/PSD Mascot/PSD Mascot/v0.4.1` です。v0.4.0以下の設定は読み取りのみで引き継ぎ、旧版フォルダ・元PSD・既存PNGは変更しません。

放置機能はv0.4.0のschema 6で `idle` 項目として追加しました。現在のschema 7でも同じ内容を保存します。古い設定にこの項目がなくても、空の一覧と初期範囲で読み込めます。待機中の残り時間や一時的な放置表情は保存せず、次回起動時は元の表情から新しく待機します。PNGの形式・キャッシュキーは変更していません。

## ログ機能

オフで開始した通常の描画・一括生成は計測集計を省略し、新しいログファイルを作りません。オンの場合はexeと同じ階層の `logs/cache-performance-*.json` に、描画・キャッシュ生成の回数と所要時間を記録します。

開始時と完了時にログがオンの処理が記録対象です。オンに切り替える前から進行していた処理は記録されない場合があります。オフへ切り替えても既存のログは残します。RAM内の完成画像を切り替えるだけの通常のまばたき・口パクでは、オンでもログファイルを増やしません。

ログにはPSDのパス・レイヤー状態の識別ハッシュ等が含まれます。保存先へ書けない場合は `%TEMP%/PSD-Mascot/logs` を試し、そこにも書けなくても画像生成を継続します。

`kind: bulk_cache` が一括生成の集計です。`psd_composite` は全体合成、`region_composite` は領域再合成の時間です。`fast_render` は領域合成・変換等を内包するため、全工程を単純に足すと二重計上になります。全体は `total` を確認してください。`renderer_seed_full`、`renderer_fast`、`renderer_fallback` 等のカウンタで使用経路を確認できます。

`tools/benchmark_region.py` は明示的な診断用ツールなので、設定タブの初期値に関係なくログを有効化して測定します。

## 既存機能とデータ

タブは「レイヤー／服装／表情／動き／リアクション／放置／セリフ／設定」です。PSDのレイヤー切替、服装と表情プリセット、眉・目・口・アクセサリの制御、当たり判定、音声再生と口パクは従来どおり利用できます。音声はmp3・wav・oggに対応し、exeと同じ階層のvoiceフォルダで管理します。

v0.3.8の共通画像＋領域再合成を継続しています。RGB8bit・フラットな通常描画のピクセルレイヤー等、検証済みの条件で使い、マスク・クリッピング・効果・グループ・特殊描画モードなどは従来の全体合成へ戻します。高速処理の例外時もレイヤー状態を復元して全体合成で再試行します。

共通画像は最大128MiB・8枚で保持します。表示用RAMキャッシュやPSD・合成作業領域は別です。初回の基本画像の全体合成、共通画像の保持上限、変更領域の大きさによっては待ち時間が残ります。

PNG形式（RGBA・長辺最大1400px）・キャッシュキー・既存の服装や表情等の項目形式は維持しています。PSD別設定には前述のidle項目を追加しています。旧版のcacheフォルダを新版exeの横へコピーすると、PSDのパス・内容・ライブラリ版が同じ場合に再利用できます。旧版フォルダを削除・移動する必要はありません。配布物にはユーザーの生成済みPNGやログを含めません。

グローバル設定とPSD別設定の新しい保存先は `%APPDATA%/PSD Mascot/PSD Mascot/v0.4.1` です。旧版設定は読み取りのみで引き継ぎ、元PSDは書き換えません。

## ソースから起動・ビルド

Python 3.12.0を使用してください。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip --isolated install --require-hashes -r requirements-lock.txt
$env:PYTHONPATH="src"
.venv\Scripts\python.exe launcher.py
```

上の手順ではsrcを検索パスへ追加しています。exeは `build.ps1` で作成でき、出力は `dist/Simple-PSD-Mascot-v1.0.0/` フォルダです。配布時のライセンス・対応ソースの同梱と再構築手順は `BUILD.md` を参照してください。依存ライブラリは検証済みの版に固定しています。
