# Simple PSD Mascot v1.0.1

**お気に入りの立ち絵を、デスクトップのマスコットに。**

Simple PSD Mascotは、自分で用意したPSDファイルを読み込み、キャラクターをデスクトップに表示するWindows用アプリです。

レイヤーを切り替えて服装や表情を保存したり、まばたきや口パクを設定したりできます。キャラクターに触れたときの反応や、しばらく操作していないときの表情・音声も設定できます。

このアプリの開発にはCodexを使用しています。

**Windows版はPythonのインストール不要です。** PSDと音声素材は付属していないため、利用者自身で用意してください。

## 前回のPSDを自動で開く

最後に正常に読み込めたPSDの絶対パスを、AppDataのapp-settings.jsonに保存します。次回起動時に同じPSDを読み込み、削除・移動されて見つからない場合は警告を表示します。「PSDを開く」から選び直してください。初回はPSDを手動で開いてください。

設定保存先は %APPDATA%/PSD Mascot/PSD Mascot/ です。アプリ設定とPSD別設定はバージョン名なしで保存します。新しい設定を優先し、未移行の設定はv0.4.1以下の旧フォルダからコピーします。旧ファイルは削除・変更しません。

PSDのパスはPC内の設定に保存し、外部送信しません。設定ファイルを共有するときはユーザー名やフォルダ名に注意してください。

## できること

| 機能 | 内容 |
|---|---|
| レイヤー切り替え | PSD内のパーツの表示・非表示を変更 |
| 服装の保存 | 衣装などのレイヤー構成を保存・呼び出し |
| 表情の保存 | 「動き」で設定した表情の組み合わせを保存・呼び出し |
| 立ち絵の動作 | 眉・目・口・アクセサリの設定、まばたき、音声再生時の口パク |
| タッチへの反応 | クリック・タップする範囲を作り、表情や音声を呼び出し |
| 放置時の動作 | 設定した待ち時間の範囲からランダムに動作を実行 |
| 音声再生 | WAV・MP3・OGGを登録して再生。字幕表示はありません |
| 表示の調整 | 立ち絵の大きさ、最前面表示、アプリのフォント倍率などを変更 |

保存した設定の組み合わせを「プリセット」と呼びます。服装や表情などのプリセットはPSDごとに管理できます。

## 動作環境

- Windows 10 / 11の64ビット版（x64）を想定
- Microsoft Visual C++ x64ランタイムが必要
- Windows用exe版ではPythonは不要
- ソースから実行する場合はPython 3.12.0を使用

動作確認はWindows 11で行っています。すべてのWindows環境やPSDでの動作を保証するものではありません。PSDの構成や画像サイズによって、読み込み・表示の再現性・処理時間は異なります。

## はじめ方

1. **Microsoft Visual C++ x64ランタイムをインストールします。**  
   [Microsoft公式案内](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)から確認するか、[公式x64版インストーラー](https://aka.ms/vc14/vc_redist.x64.exe)を取得してください。対応版がすでに入っている場合、追加インストールは不要です。

2. **Windows配布ZIPを全体ごと展開します。**  
   書き込み可能なフォルダに展開してください。`_internal`などの同梱フォルダも必要なので、exeだけを取り出さないでください。

3. **`Simple-PSD-Mascot.exe`を起動し、PSDを開きます。**

4. **レイヤーや動きを設定し、立ち絵をデスクトップに表示します。**

未署名のexeのため、Windowsで警告が表示される場合があります。

## 各タブの使い方

### レイヤー・服装

「レイヤー」で表示するパーツを選び、「服装」で衣装などの組み合わせを保存します。

保存した服装の「着替え」チェックボックスをオンにすると、デスクトップ上の立ち絵を右クリックし、「着替え」から呼び出せます。

### 動き・表情

「動き」で、眉・目・口・アクセサリに使うレイヤーを設定します。「表情」では、その組み合わせをプリセットとして保存・呼び出しできます。

音声再生時の口の動きは、「設定」で次の3種類から選べます。

- 開けっ放し
- 口パク
- 動かさない

### リアクション

立ち絵に触れたときの反応を設定します。

右側のプレビューで四角い反応範囲を作り、位置と大きさを調整してください。範囲ごとに、呼び出す表情・セリフ・表情の持続時間を指定できます。

反応範囲の枠は、「リアクション」タブを開いているときだけプレビューに表示されます。

### 放置

マスコットやこのアプリを操作していないときの動作を設定します。

待ち時間の下限・上限を指定すると、その範囲からランダムに待ち時間が決まります。実行するアクションも、有効な項目の中からランダムに選ばれます。

アクションには表情・セリフ・表情の持続時間を指定できます。自動実行は、立ち絵をデスクトップに表示している間に行われます。

**他のアプリでのマウス・キーボード操作は、放置時間をリセットしません。** マスコットやこのアプリを操作すると待ち時間を取り直し、実行中の放置アクションを中断します。

### セリフ

WAV・MP3・OGG形式の音声をプリセットとして登録できます。

「ボイス」チェックボックスをオンにした項目は、立ち絵の右クリックメニューから再生できます。リアクションや放置アクションから呼び出すこともできます。

表情の持続時間が終わっても、セリフは途中で停止せず最後まで再生します。ただし、ユーザー操作によって放置アクションを中断した場合は、そのアクションの音声も停止します。

### 設定

次の項目を調整できます。

- 立ち絵の最前面表示・デスクトップ表示倍率
- まばたきの間隔・口パクの種類
- アプリのフォント倍率
- キャッシュの削除
- デバッグログのオン・オフ

「設定タブのリセット」は、このタブの設定だけを初期値に戻します。PSDや各プリセット、音声、生成済みキャッシュは削除しません。

## キャッシュについて

表示用に生成した画像を保存し、同じ状態を表示するときに再利用します。事前キャッシュを生成しておくこともできます。

生成時間はPSDのサイズやレイヤー構成、組み合わせの数によって変わります。初回の生成には時間がかかる場合があります。

キャッシュはPSDごとに管理され、「設定」の「キャッシュの削除」から選んで削除できます。元のPSDは削除・変更しません。

## データの保存場所

| データ | 保存場所 |
|---|---|
| 音声 | exeと同じ階層の`voice`フォルダ |
| 画像キャッシュ | exeと同じ階層の`cache`フォルダ |
| アプリ設定・PSD別設定 | `%APPDATA%/PSD Mascot/PSD Mascot/` |
| デバッグログ | 通常はexeと同じ階層の`logs`フォルダ |

設定保存先はバージョンに依存しません。旧設定は必要時にコピーして引き継ぎ、旧ファイルは保持します。

ログは初期状態でオフです。有効にすると、処理回数や所要時間などを記録します。ログにはPSDの保存先パスなどが含まれるため、公開・共有する際は内容を確認してください。

## 終了方法

メインウィンドウを閉じるとアプリは終了します。

通知領域のアイコンから「終了」を選ぶこともできます。「開く」またはアイコンのダブルクリックでメイン画面を表示できます。アイコンはWindowsの「隠れているインジケーター」に入る場合があります。

## ソースからの実行

Python 3.12.0で、次のコマンドを実行します。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip --isolated install --require-hashes -r requirements-lock.txt
$env:PYTHONPATH="src"
.venv\Scripts\python.exe launcher.py
```

Windows用exeのビルド手順は`BUILD.md`を参照してください。
